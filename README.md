# KitTrack

## DESCRIÇÃO
**O que é?** 
 Ele é um sistema web em desenvolvimento 
 
**Qual problema resolve?**
O KitTrack tem como objetivo registrar a distribuição e a entrega dos kits aos transmissores responsáveis por cada aula, acompanhar as devoluções e identificar equipamentos ou itens que estejam pendentes de retorno. Dessa forma, o sistema pretende reduzir a conferência manual e evitar retrabalho.

**O que controla?**

1. Composição dos kits:
Cada kit contém uma câmera, um microfone, um passador e um subkit com três pincéis

2. Controle operacional:
O sistema acompanha a distribuição dos kits, entrega aos transmissores, devoluções dos equipamentos e itens pendentes de retorno.
